# Security policy

Please report a suspected vulnerability through [GitHub private vulnerability reporting](https://github.com/arkts-dev/deus/security/advisories/new). Include a concise reproduction, affected version, expected and observed behavior, and potential impact. Do not post credentials, exploit details, or private project content in a public issue.

The supported release is `v0.3.0`. Security fixes are validated against the pinned Pi and Dexter bridge contracts before publication. A disclosure report does not authorize access to another person's systems or data.
